# OrangeHRM Manual Test Points

## Login

### 正常场景

1. 正确用户名 + 正确密码
   - 预期：登录成功并进入 Dashboard

### 异常场景

2. 正确用户名 + 错误密码
3. 错误用户名 + 正确密码
4. 用户名为空
5. 密码为空

### 边界 / 其他

6. 用户名前后空格
7. 密码大小写
...

2. 填写完整信息创建员工

3. First Name 为空
